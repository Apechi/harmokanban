## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gaps between avatar and badge, inline padding for system logs |
| sm | 8px | Message bubble padding, chat input spacing, scrollbar gutters |
| md | 16px | Padding inside drawer, gap between messages, header padding |
| lg | 24px | Layout boundaries, footer padding, list margins |
| xl | 32px | Drawer offset gaps (if any) |
| 2xl | 48px | Drawer width sizing padding / boundaries |
| 3xl | 64px | Not applicable |

Exceptions:
- Drawer width: fixed at 360px on desktop, full screen on mobile.

| Display (Unread count badge) | 10px | 700 (Mono) | 1.0 |

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | var(--brand-bg) | Drawer background, message stream container |
| Secondary (30%) | var(--brand-card) | Message input container, own message bubble background, system event background |
| Accent (10%) | var(--brand-accent) | Drawer toggle button indicator, unread badge, peer callsigns |
| Destructive | var(--brand-destructive) | Disconnected / connection lost warning status indicator |

Accent reserved for:
- Chat drawer toggle button badge and ping ring
- Send button icon / action state
- Clickable links in chat message text
- Active room callsign highlighting
